# [Altsia] Language Support for [Fresh]

Syntax highlighting and LSP integration for [Altsia].

## Installation

Use Package: Install from URL in the command palette (`Ctrl+P`) and enter:

```
https://github.com/altsia/altsia#fresh-altsia
```
